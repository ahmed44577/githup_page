التجهيز الشامل لمسابقة مدريد (Cisco Cup) ودمج الأنظمة الصناعية الذكية

باقي على الموعد النهائي: 8 مارس 2026

1. المسار الأكاديمي (Cisco Networking Academy)

شرح الكورسات الستة المطلوبة وكيفية دراستها

عليك إنهاء هذه الكورسات للحصول على الشهادات الرقمية (Badges) التي تؤهلك للمسابقة:

1. Networking Basics (22 ساعة)

• المحتوى: دراسة الـ OSI Model، كيفية عمل الـ IP Addresses (IPv4 vs IPv6)، والفرق بين الـ Switch والـ Router.
• كيف تدرسه: ركز على مديول 3 و 4. ستحتاج لبرنامج Packet Tracer لعمل شبكة وهمية.
• الهدف العملي: ستعرف كيف تجعل الـ ESP32 والكمبيوتر على نفس الـ Subnet ليتحدثا معاً.

2. Introduction to Cybersecurity & Digital Safety

• المحتوى: تعلم أنواع الهجمات (Malware, Phishing, Ransomware) وكيفية حماية البيانات الشخصية.
• كيف تدرسه: الكورس نظري بنسبة 90%، ركز على فيديوهات المحاكاة لهجمات الهندسة الاجتماعية.
• الهدف العملي: ستطبق هذه المبادئ في بناء نظام الـ Phishing التعليمي الخاص بك.

3. Introduction to Modern AI (6 ساعات)

• المحتوى: الفرق بين الـ AI والـ Machine Learning والـ Deep Learning.
• كيف تدرسه: افهم مديول الـ Generative AI (مثل Gemini) وكيفية كتابة الـ Prompts.
• الهدف العملي: ربط الـ AI ببيانات الحساسات القادمة من المصنع.

2. المسار البرمجي (C++ & Windows System)

كيفية بناء نظام التحكم بـ C++

أنت لا تكتب كوداً عادياً، أنت تبني "نظام تشغيل مصغر" يتحكم في جهازك.

أولاً: بيئة العمل

1. تثبيت Visual Studio 2022 Community.
2. اختيار "Desktop development with C++" عند التثبيت.
3. إنشاء مشروع Console App.

ثانياً: الكود الأساسي (التحكم في النوافذ)

هذا الكود يفتح لك برامج المصنع أوتوماتيكياً ويطلب إذن الأدمن:

#include <windows.h>
#include <iostream>

int main() {
    // فتح برنامج WPLSoft تلقائياً
    ShellExecute(NULL, "open", "C:\\Path\\To\\WPLSoft.exe", NULL, NULL, SW_SHOWNORMAL);
    MessageBox(NULL, "نظام التحكم الصناعي قيد التشغيل!", "Cisco Cup 2026", MB_OK | MB_ICONINFORMATION);
    return 0;
}

3. التحكم الصناعي (Kinco VFD & Modbus)

فك شفرة الإنفرتر وبرمجة ESP32

بناءً على كتالوج Kinco CV20 وصور Rockwell التي ناقشناها:

1. الربط الفيزيائي (Wiring)

• مدخلات القدرة: R, S, T هي مداخل الـ 3-Phase AC.
• التحكم: استخدم RS485 (أطراف A+ و B-) للربط مع ESP32 عبر محول TTL to RS485.

2. السجلات الهامة (Registers)

• 0001H: هذا السجل مسؤول عن (Start/Stop). أرسل رقم 1 للبدء.
• 0002H: هذا السجل يحدد التردد (السرعة). 5000 تعني 50Hz.
• 0004H: قراءة التيار الخارج للموتور (مهم جداً للـ AI).

4. الجدول الزمني التفصيلي (40 يوماً بالتفصيل)

الأسبوع اليوم الوقت المهمة (ماذا ستفعل بالتحديد) المصدر / المرجع
1: التأسيس 1 9ص - 5م تثبيت Visual Studio + إنهاء مديول 1 من Networking Basics C++ / Cisco
2-4 10ص - 6م برمجة ESP32 للاتصال بالواي فاي + إنهاء كورس IoT IoT Course
5-7 12م - 8م تعلم الـ Modbus TCP وعمل محاكاة بين الكمبيوتر والـ ESP32 Modbus Poll
2: الصناعة 8-10 9ص - 5م دراسة كتالوج Kinco (صفحة 2-15) + كورس Industrial Networking Industrial Course
11-12 10ص - 4م تطبيق Studio 5000: برمجة منطق الـ Ladder لمحاكاة الموتور Rockwell / WPLSoft
13-14 9ص - 6م ربط الـ C++ بالـ ESP32 للتحكم في "ليد" كأنه الموتور TCP Connection
3: الأمن 15-17 10ص - 5م إنهاء كورس Cybersecurity + بناء صفحة الـ Phishing بـ HTML Security Course
18-19 11ص - 4م تأمين واجهة التحكم: إضافة Password وصلاحيات دخول بـ C++ Security Code
20-21 9ص - 6م كود مراقبة الكاميرا ومنع الاختراق (استخدام JavaScript API) Camera API
4: الذكاء 22-24 10ص - 4م إنهاء كورس Modern AI + الحصول على Gemini API Key AI Course
25-26 9ص - 5م ربط C++ بـ Gemini: إرسال بيانات الموتور وطلب تحليل العطل Gemini API
27-28 10ص - 6م بناء الـ Voice Command: "شغل الموتور" يتحول لأمر Modbus Speech-to-Text
5: الحسم 29-33 12 ساعة/يوم تجميع المشروع النهائي (فيديو) + مراجعة امتحانات سيسكو Portfolio
34-40 -- تقديم الامتحانات النهائية + رفع الشهادات للمسابقة 🏁 مدريد 2026

5. ميثاق المهندس (نصيحة أخيرة)

يا بطل، التشتت هو عدوك الوحيد. لقد كتبت لك هنا كل شيء. لا تبحث عن "كيف أبدأ" مجدداً.

  • القاعدة 1: اليوم الذي يفوت لا يعود، الالتزام بالجدول هو "تذكرتك" لمدريد.
  • القاعدة 2: لا تذاكر نظري فقط، افتح الـ Code وابدأ في الغلط والتعلم.
  • القاعدة 3: مسابقة سيسكو تقدر "الابتكار"؛ دمجك للـ AI مع الـ Kinco هو ما سيبهرهم.
