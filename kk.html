أولاً: محور الأمن السيبراني (Cyber Defense)

1. كورسات سيسكو الأمنية (الدراسة النظرية)

كورس Introduction to Cybersecurity: دراسة مثلث الأمان (CIA Triad): السرية، السلامة، والتوافر. تعلم كيفية صد هجمات DDoS التي تستهدف الأنظمة الصناعية.
كورس Digital Safety: فهم الهندسة الاجتماعية (Social Engineering). كيف يحاول المخترق سرقة كلمة مرور لوحة تحكم المصنع عبر إيميل مزيف.

2. مشروع الـ Phishing التعليمي (تطبيق عملي)

المهمة: بناء "صفحة صيد" وهمية لإقناع المهندسين بتغيير كلمة المرور. التنفيذ: 1. كود HTML يحاكي واجهة تسجيل دخول Cisco أو Kinco.
2. كود JavaScript يجمع البيانات (لأغراض تعليمية) ويخزنها في ملف نصي عبر Node.js.
3. شرح كيفية اكتشاف التزوير (رابط الصفحة، شهادة SSL).

3. أمن المراسلات والـ OSINT

المهمة: تأمين إيميلات المصنع. التنفيذ: دراسة سجلات الـ DNS (SPF, DKIM, DMARC) لمنع انتحال شخصية مدير المصنع في الإيميلات.

ثانياً: محور البرمجة والتحكم (C++ & Kinco)

1. برمجة الويندوز والـ Agent (C++)

المهمة: بناء برنامج C++ يتحكم في بيئة العمل. التنفيذ: استخدام ShellExecute لفتح WPLSoft وبرامج سيسكو بضغطة واحدة. ShellExecute(NULL, "open", "C:\\WPLSoft.exe", NULL, NULL, SW_SHOWNORMAL);

2. فك شفرة كتالوج Kinco CV20

الربط الكهربائي: توصيل الأطراف R, S, T بالكهرباء (3 فاز) وتوصيل U, V, W بالموتور.
عناوين المودباس (Registers): • العنوان 0001H: Control Word (قيمة 1 للتشغيل، 2 للتوقف).
• العنوان 0002H: Frequency Reference (قيمة 5000 تعني 50 هرتز).

3. وسيط البيانات (ESP32)

المهمة: تحويل أوامر الواي فاي إلى أوامر صناعية RS485. التنفيذ: استخدام مكتبة ModbusIP_ESP32 لاستقبال الأرقام من برنامج C++ وإرسالها للإنفرتر.

ثالثاً: محور الذكاء الاصطناعي (AI Integration)

1. العقل المفكر (Gemini API)

المهمة: ربط الحساسات بذكاء جوجل. التنفيذ: إرسال بيانات التيار والحرارة من الـ ESP32 لـ Gemini API وطلب تحليل: "هل الموتور هيحترق؟".

2. التحكم الصوتي (Voice Control)

المهمة: "شغل الماكنة" بالصوت. التنفيذ: استخدام Web Speech API في المتصفح لتحويل الكلام لنص، ثم إرسال النص لـ C++ لتنفيذ أمر التشغيل.
